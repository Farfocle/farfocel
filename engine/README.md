#intrinsics Farfocel Game Engine

## Core

The abyss you do not want to stare into for too long. Collection of data
structures, utils and helpers created in the spirit of the Farfocel. Nothrow,
minimal, pragmatic and probably not very robust. Examples are placed in
`/examples/core/`. Documentation generated by Doxygen.

### Polymorphic allocators

- [x] Allocator protocol
- [x] `HeapAlloc` - forwards to `malloc` or `new`\`delete`
- [x] `BlockAlloc`- allocates memory in chunks that can be freed idividually
- [x] `ArenaAlloc` - allocates memory in a linear fashion on one buffer that can
      be only freed all at once, no individual frees
